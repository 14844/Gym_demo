# IRON PULSE — ديمو موقع جيم

افتح `index.html` بدبل كليك (Chrome أو Edge). محتاج نت عشان الصور وThree.js وGSAP والخطوط بتيجي من CDN.

## الصفحات
- `index.html`: الرئيسية (دمبل 3D، الإحصائيات، المميزات، البرامج، حاسبة BMI، آراء الأعضاء)
- `programs.html`: البرامج، جدول الكلاسات، المدربين، الأسعار (شهري/سنوي)، الأسئلة الشائعة
- `contact.html`: العنوان، المواعيد، استمارة الاشتراك، الخريطة

## تغيير هوية العميل
1. **الألوان**: أول جزء في `css/style.css` (`:root`). غيّر `--brand` و`--brand-2` والموقع كله بيتغير، ومعاه إضاءة المجسم الـ 3D.
2. **اللوجو**: بدّل `assets/logo.svg` بلوجو العميل وخلّي الاسم زي ما هو (أو غيّر `src` في الـ navbar والـ footer).
3. **الاسم**: دوّر على `IRON` و`PULSE` في ملفات الـ HTML الـ 3 واستبدلهم.
4. **الخطوط**: `--font-ar` و`--font-display` + لينك Google Fonts في `<head>`.
5. **الترجمة**: كل نص عربي معاه `data-en="..."` للنسخة الإنجليزي.
6. **الواتساب**: غيّر `wa.me/201000000000` في الـ 3 صفحات.
